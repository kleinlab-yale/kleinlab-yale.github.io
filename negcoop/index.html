Interactive RTK Teaching App

Weak dimerization can stretch signaling into a long, low plateau until receptor abundance tips the same system into a burst.

This GitHub Pages-ready app is a qualitative teaching model for how receptor abundance, dimerization strength, cooperativity, and internalization reshape RTK output. It is tuned to illustrate the narrative you described from your Molecular Cell paper: low sustained signaling can bias differentiation, while high transient signaling can bias growth.

Model note: this interface is deliberately simplified for students; it captures the qualitative logic rather than a full methods-level reconstruction.

Model structure

The simulator is now tuned as a teaching model for the curve shapes you asked for. It uses three linked ideas:

  1. Receptor abundance, ligand, cooperativity, and Kd set an effective dimerization drive that decides whether the response is mostly transient or mostly sustained.
  2. A fast transient component peaks near 2 minutes, while a weak negative-cooperative regime adds a low plateau that can persist for 30 to 60 minutes.
  3. Strong signaling drives rapid receptor loss from the surface, which makes transient responses crash even if ligand is still present.
